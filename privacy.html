1. Introduction

Welcome to SPACE-MD, a WhatsApp multi-device bot developed by DARK-EYE-OFC. This Privacy Policy explains how we handle your data. By using SPACE-MD, you agree to this policy.

2. Data We Collect

  • WhatsApp Data: We do NOT store your WhatsApp messages, media, or chats on external servers. All message processing happens in real-time on your hosting server.
  • Session Data: Your WhatsApp session (creds.json) is stored locally on your VPS / Panel where you deployed the bot.
  • Group Data: Group IDs, participant IDs for features like welcome, goodbye, anti-link are stored in local JSON database (database/ folder).
  • User Commands: We log commands for debugging (.hd, .play, etc) but not message content.

3. What We DON'T Collect

  • ❌ We don't collect your WhatsApp password
  • ❌ We don't read your private chats
  • ❌ We don't sell data to third parties
  • ❌ We don't upload your media to external servers (except when you use tools like .hd, .play which require external APIs)
  • ❌ We don't store credit cards, location, contacts

4. Third-Party APIs

Some features use external APIs:

  • .play, .song, .video - Uses YouTube API
  • .hd, .enhance - Uses image upscale APIs
  • .ai, .gpt - Uses OpenAI / AI APIs
  • .sticker - Processed locally

We are not responsible for their privacy policies.

5. Data Storage

All data is stored locally in your deployment:

  • database/ - Group settings
  • session/ - WhatsApp login
  • Data is automatically deleted when you delete the bot / session

6. Bot Permissions

SPACE-MD requires WhatsApp permissions to read messages to respond to commands. The bot only responds to commands starting with prefix ( . ) and does not auto-read all messages.

7. Children's Privacy

SPACE-MD is not intended for children under 13. We do not knowingly collect data from children.

8. Security

We take security seriously:

  • Session files are encrypted
  • Owner-only commands (.terminal, .bash) are restricted to owner numbers
  • We recommend hosting on your own VPS / private panel

9. Your Rights

  • You can delete your session anytime with .delsession or deleting creds.json
  • You can disable features (.goodbye off, .welcome off)
  • You can remove bot from group to stop data processing

10. Changes to Policy

We may update this policy. Updates will be posted on support-black-eight.vercel.app/privacy
